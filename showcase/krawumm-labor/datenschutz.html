Was diese Demo im Browser tut

Die Seiten bestehen aus statischem HTML, CSS und JavaScript. Die drei Mini-Experimente reagieren lokal auf Regler und Schaltflächen. Es wird kein Audio abgespielt, kein Nutzerprofil erstellt und kein Ergebnis an einen Server übertragen.

Gruppenformular

Das Formular auf der Gruppenseite prüft Eingaben ausschließlich im Browser. Beim Absenden wird die Übertragung verhindert und eine Demo-Bestätigung angezeigt. Die Eingaben werden weder gespeichert noch versandt. Bitte tragen Sie dort keine echten personenbezogenen Daten ein.
