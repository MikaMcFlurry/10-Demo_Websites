2. Was diese Website verarbeitet

Diese Website ist eine statische Demonstration. Sie setzt keine Cookies, bindet keine Tracker, keine Analysedienste, keine Kartendienste, keine Social-Media-Plugins und keine externen Schriften ein. Alle Schriften werden lokal ausgeliefert; beim Aufruf entsteht keine Verbindung zu Dritt-Servern.

Chromfläche auf der Startseite

Die Chromdarstellung wird vollständig im Browser gerechnet (WebGL). Es wird keine Grafik von einem Server geladen, nichts übertragen und nichts gespeichert. Die Mausposition steuert nur die Lichtrichtung und verlässt den Browser nicht.

Schichtzeitrechner und Maßstabswechsel

Beide rechnen ausschließlich im Browser. Eingaben werden weder übertragen noch gespeichert; es gibt keinen Absenden-Knopf.
